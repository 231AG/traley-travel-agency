# Tarley Travel website: final report

The Tarley Travel LLC website: one design (Design A, built from the approved mockup), one content layer, one quote flow. A second design (B, "Departures") was built for comparison; the owner chose Design A on 4 October 2026 and Design B was removed from the codebase. Every page passes the brief's budgets, and facts Tarley has not supplied appear as visible, tracked placeholders. Phase-by-phase audits are in `docs/phase-reports.md`.

## 2. What was built, and how to run and deploy it

- **Stack**: Astro 7 static output, TypeScript (strictest), Tailwind CSS 4 with brand tokens only, self-hosted subset fonts, `zod/mini`, `sharp` image pipeline, Playwright + axe-core, Lighthouse, Vitest, ESLint, Prettier. Astro replaced Next.js because an empty Next.js 16 static page already ships about 133 KB of gzipped JS against the 100 KB budget (decision D1 in `PLAN.md`); this site ships at most 11 KB.
- **Pages**: home, flights & hotels, visa assistance, six visa destination pages (US, UK, Canada, Schengen Area, UAE, China), Liberia concierge, about, contact, 404.
- **Quote flow**: Flights / Visa / Concierge tabs; validation; a live boarding-pass stub; every service and destination button opens the right tab already filled in; `?quote=visa&to=Canada` deep links; the message opens in WhatsApp (`wa.me/231886504519`) with empty fields left out. It handles blocked popups, double clicks and edits after sending.
- **Content**: everything in `src/content/site.ts`. `PLACEHOLDERS.md` and `CREDITS.md` are generated from it.
- **Run**: `npm install`, `npm run dev`. **Check**: `npm run check`. **Deploy**: Cloudflare Pages, build command `npm run build`, output `dist`, `NODE_VERSION=22`, custom domain `www.tarleytravel.com`. Details are in `README.md`.

## 4. Deviations from the mockup

| Deviation                                                                                                         | Reason                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| No text below 15 px (mockup labels and footer were about 12–13 px)                                                | The brief's minimum                                                                                         |
| Gold text #866510 instead of #9A7414; input borders #767F94                                                       | Contrast: the original values measured 4.30:1 and 1.31:1                                                    |
| "Office in Monrovia" replaces "Registered in Liberia [REG. NUMBER]"                                               | The owner chose not to show a registration number                                                           |
| Payment line names mobile money, Sendwave and bank transfer                                                       | The owner's actual methods (the mockup showed Orange Money and MTN MoMo)                                    |
| Destination cards say "Start a request" and "Visa details", not "See requirements"                                | The site never lists requirements; the button opens the visa form and the link goes to the destination page |
| No hero photo on phones                                                                                           | Saves 35–60 KB on mobile data and keeps the quote form high on the screen                                   |
| Footer logo on a white plate                                                                                      | No reversed (white and gold) logo file exists yet                                                           |
| Nav logo is a crop of Logo A's wordmark                                                                           | The mockup shows a wordmark; Logo B has a photo background and is too small                                 |

6. **Facts to confirm**: the email domain (`tarleytravelllc.com` vs the website's `tarleytravel.com`), the office address spelling, the service promises carried over from the mockup and expanded on inner pages, and which visa types Tarley handles per country.

## 6. Known issues and next steps

1. **No pull request yet.** The repository has no `main` branch, so a PR cannot be opened. Everything is on `claude/new-session-m7djov`. Create `main` (or tell me which branch is the base) and I can open one.
2. **Logo files.** The site uses a straight crop of Logo A. Please supply SVGs: the horizontal lockup, a reversed (white and gold) version for navy, and the mark on its own. The footer plate goes away once the reversed version exists.
3. **Email domain.** `info@tarleytravelllc.com` is on a different domain from the website (`tarleytravel.com`). Confirm it receives mail, or set up `info@tarleytravel.com`.
4. **Photos.** Real photos of the team and the office front should replace the two placeholders. Tarley's own photos of trips or the office would also be better than the two CC0 stock photos.
5. **Facts to confirm.** Service promises and visa types listed in `PLACEHOLDERS.md` need a yes from Tarley before launch.
6. **Links to recheck.** `npm run check:links` cannot reach the US State Department or Instagram from a server (they refuse automated requests). Both were correct when built; recheck them by hand every few months.
7. **Code.** The quote logic is split into `src/lib/quote/fields.ts` (pure reading and validation, unit-tested), `floating-button.ts` and `controller.ts` (the DOM wiring, 312 lines).
8. **Repository size.** The handover screenshots (about 30 MB of PNGs in `screenshots/desktop` and `screenshots/mobile`) can move to a release attachment or Git LFS once reviewed. Earlier commits still hold the Design B screenshots; rewriting history to drop them is possible but not done.
9. **Unsplash connector.** It needs the Unsplash account's email address confirmed before it can be used for future photos.

Next steps: fill the placeholders, choose a design, add the Cloudflare Pages project and domain, and turn on analytics with a Cloudflare Web Analytics token if wanted.

## 7. Design decision

The owner chose **Design A** on 4 October 2026. Design B ("Departures") was removed: its pages, components, stylesheet, two fonts and their npm packages, its tests, its screenshots and the `/b` handling in headers, sitemap and SEO. The folders were flattened now that there is one design (`src/components`, `src/layouts`, `src/lib`). Design B stays in the git history (commits up to `40019ca`) if it is ever wanted again.
